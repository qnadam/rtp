# SearXNG

A SearXNG egy nyilt forraskodu, adatvedelem-fokuszalt metakereso motor: tobb
kereso szolgaltatas (pl. Google, Bing, DuckDuckGo, Brave) talalatait gyujti
ossze egy helyen, anelkul, hogy naplozna a kereseseidet vagy profilt epitene
roled. A sajat peldanyod teljesen a sajat kezedben van, kulso szolgaltatonak
nem adja at az adataidat.

A titkositokulcsot a kontener maga generalja az elso induraskor, kulon
beallitas nelkul.
